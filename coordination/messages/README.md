# Outboxes

One file per desk. Append with `python3 scripts/post.py`. Do not edit another desk's file. Do not rewrite history above your new entry.

| File | Who appends |
| --- | --- |
| `orchestrator.md` | orchestrator |
| `frontend.md` | frontend |
| `backend.md` | backend |
| `platform.md` | platform |
| `human.md` | a person, via `--from human:name` |

Read all of them. The newest entry is at the bottom. The orchestrator turns decisions into job-board updates. A message that never reaches the board is invisible to a desk that only had time to read the sheet.
